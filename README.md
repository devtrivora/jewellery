# LUMIÈRE Jewellery — Frontend Demo

A premium, minimalist jewellery e-commerce frontend built with React + Vite.

## Features
- Responsive luxury jewellery UI
- Clickable category navigation
- Product quick-view modal
- Wishlist
- Cart with quantity controls
- Search drawer
- Login/profile drawer
- Frontend-only checkout/payment simulation
- Newsletter interaction
- No backend, database, authentication service, or real payment processing

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Images
Product imagery uses remote Unsplash image URLs for the demo. The public Unsplash jewellery search is a useful source for additional imagery: https://unsplash.com/s/photos/jewelry

## Important
The payment UI is deliberately a frontend simulation. Do not enter real card details.
